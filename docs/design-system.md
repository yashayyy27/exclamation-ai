# ! — original identity

The product name is exactly **!**. The repository slug is a technical identifier. The symbol uses an original tapered stem and separated red circular dot, preserving legibility at favicon size. It has an explicit accessible name. It is not an R/GA asset or a claim of affiliation.

The palette in `apps/web/src/tokens.css` uses near-black #0B0B0D, warm white #F5F5F2 and signal red #EF2929. Small red text uses darker #C91818 for contrast. Neutral surfaces, thin rules, oversized typographic hierarchy and a split editorial hero express evidence and decisive action. General creative context: [R/GA](https://rga.com/); no logo, assets or layout copied.

System Arial/Helvetica provides readable UI and editorial headlines without font downloads. Monospace labels distinguish source and audit metadata. Tabular figures align metrics. Native semantic controls, labels, focus outlines, a skip link, dialog focus trapping and Escape support provide keyboard access.

Motion uses 180ms transitions and initial chart/exclamation entrance. `prefers-reduced-motion` disables transitions and animation. Charts are interactive buttons with accessible values and a drilldown explanation. Responsive layouts collapse the sidebar and charts; no decorative filters are shown on source-independent event QA and recorded evaluation pages.

Actual screenshots live in `docs/screenshots/`. Browser tests capture the running UI rather than generate mockups. Visual QA covers 1440×1000 desktop and 390×664 mobile layouts, overflow, all navigation, stage drilldown, store dialogs and client exports. Axe checks are automated evidence, not a full accessibility certification. Human screen-reader and wider device testing remain next steps.
